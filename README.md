# Agenda de Rastreios

Calendário de rastreios para subscrever no Outlook. É actualizado automaticamente a partir da agenda partilhada.

Link de subscrição:

    https://raw.githubusercontent.com/ItaCarvalho/agenda-de-rastreios/main/rastreios.ics

O ficheiro não inclui telefones nem emails dos clientes. `gerar_ics.py` gera o ficheiro a partir dos dados da agenda.
